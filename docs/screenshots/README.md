# Screenshots

The main README references four images in this folder. Add them here with these
**exact filenames** and they'll render automatically:

| Filename | What to capture |
|--------------------|-----------------------------------------------------------|
| `dashboard.png` | The main view — sidebar stats/streak/heatmap + a problem list |
| `problem-detail.png` | A problem expanded, showing the rating, notes, and "Dates solved" |
| `activity-log.png` | The Activity log dialog with a date range of results |
| `share.png` | The Share dialog (share card + snapshot link) |

## How to capture (macOS)

1. Run the app: `npm run dev`, open the localhost URL.
2. Press **⌘ + Shift + 4**, then drag to select the region (or press **Space** to
   capture a whole window). The PNG lands on your Desktop.
3. Rename it to one of the names above and move it into this folder
   (`docs/screenshots/`).
4. Commit the files. They'll appear in the README on GitHub.

Tips: use a normal-width browser window so the two-column layout shows; both light and
dark look fine, but dark matches the app's default. Optional: keep images under ~1–2 MB.
